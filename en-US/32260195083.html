Restarting the port

The Restart port function is useful for troubleshooting and maintaining the network connectivity of BACnet devices, especially in cases where a specific port may be experiencing issues or requires a reconfiguration. By restarting the port, the BACnet device can attempt to resolve any problems and restore the normal operation of the port. During the restart process, the network port will be temporarily unavailable, which may disrupt any ongoing communication or data exchange through that port.

All data that has been temporarily stored or otherwise automatically determined for the operation of the connection will be deleted. All initialization and registration functions must be performed again.

After the restart process is complete, the network port should be restored to its normal operational state.

  2. Select  Device.
  3. Select  Infrastructure > [network port name].
  4. Select .
  5. The [Network port] properties dialog area opens.
  6. Select the Network port command drop-down list and select Restart port.
