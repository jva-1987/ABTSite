Create a BACnet reference from an EDE file import

You can create BACnet reference objects from EDE files from other BACnet devices. You can also use the context menu to create a BACnet reference object. In this way, the required BACnet referencing function is set in one step. The object is created on the top level of the favorite plant in the Plants navigation view on the left.
EDE file description

  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the BACnet references task.
  4. Select the EDE import tab.
  5. Select Import EDE.
  6. Opens the explorer dialog.
  8. Select the required EDE file and select Open.
  9. The CSV file information will appear in the EDE import window.
  10. The file drop-down menu shows the currently opened EDE file, with the naming string: Controller name where the file is saved” > “EDE file name”. The drop-down menu allows the user to select any of the previously used EDE files in the project, including the ones stored in other controllers.
  12. The Creation rules drop down menu allows multiple selection. It lets the user select which parameters can be reused from the EDE file when creating the BACnet reference object.
  13. Create a BACnet reference object, select one or more (multiselect) EDE objects and do one of the following:
    • Drag an EDE object from the EDE import area to the Plants navigation view.
    • Right-click and select Create read-only reference.
  14. A BACnet reference object is created.

Further information

  • Support EDE file import with encoding or separator
