CK_BLS: Consistency check centralized blinds values

Block CK_BLS (FB802) checks four blinds positioning values for consistency. The valid blinds positioning values are pending at the output.

Functioning

The blinds positioning values are outputted by a centralized shading application for the local shading application. These values are transmitted via separate signal paths (required by the technology). The block ensures that individually transmitted values together form a valid value set and can be outputted.

The block compares the new blinds positioning values with valid value sets for consistency based on the update indication [BlsOpUpdInd], [BlsPosNrUpdInd], [BlsHgtUpdInd] and [SlatsAglUpdInd].

The new blinds positioning values are pending at the output is the check is successful.
The existing blinds positioning values are pending at the output is the check is not successful.

The check occurs within time [TiCK].
