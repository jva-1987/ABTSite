Adapting the changeover signals

In order for the changeover signal from the plant to be shared to the RDG2 devices, a small program structure must be created in the control program. This control program must not be created in a device chart under any circumstances, as otherwise the changeover signal from the plant will not be connected automatically.

RDG2 changeover configuration area

  1. The configuration for the changeover signal on the RDG2 device is activated. This changeover signal is distributed from the plant with each RDG2 device.
    Configuring an RDG2 changeover functionality
  2. A heating/cooling plant with changeover functionality is available (HCcr21x or HCcr22x)
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Select the KNX PL-Link task.
  4. In the KNX PL-Link area, select the KNX networks > KNX PL-Link bus.
  5. Select the Changeover condition for heating area object. This object is only visible if the changeover function is set up correctly.
  7. Right-click and select Show in program.
  8. The Programming editor opens.

Adapt the changeover control program

  1. In the Project tree, select Heating/cooling circuit > Control program > Plant operating mode > Heating/cooling changeover.
  3. Open the Heating changeover function control program.
  4. In the Project tree, select Heating/cooling circuit >Resources > KNX PL-Link.
  5. Do the following:
    • Drag the Changeover condition for heating area object to the ChovrCndH FB.
    • Drag the Changeover condition for cooling area object to the ChovrCndC FB.
  1. By distributing the changeover signal in the control program, this information can be shared with every RDG2 device.
