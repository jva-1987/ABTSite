Configure and download

The Configure and download task allows you to open a work package that contains engineered devices. You can configure and load pre-engineered devices or manually configure and load devices. The work area consists of the Engineered devices and the Discovered devices tabs.

The process of downloading configurations engineered in ABT Site to discovered devices is divided into two steps.

  • Download the device network configurations
  • Download the application configuration

Downloading device configurations

Each step involves a restart of the device. In the Log viewer, check the Jobs tab to find out about the progress of the current job.

Engineering and configuration over the WAN port is not supported, no download or upload can be carried out. In this case, ABT Site must be connected directly to the BACnet/IP network.

Auto addresses all unconfigured MS/TP devices on the specified network, and only sets the network number and MAC address of the devices. A configured device must be selected so that the set baud rate operation can be issued to other devices on the network. Initially the devices set the baud rate automatically based on the baud rate of the devices already communicating on the network.

Go to ABT Go

Launches ABT Go (Windows only) for devices discovered in ABT Site.
Connecting to ABT Go

Device is authenticated via project password:
- If the project password matches the device password, ABT Go grants access to the device details page.
- If it fails, the user has to retry the login.

Note: Only IP devices are supported, with no BBMD communication. The ABT Site connection is closed when the ABT Go devices are discovered and restored when ABT Go is closed if working on a single IP.

Both applications use a single adapter:

ABT Site identifies the devices on the network using a single adapter. After making a connection from ABT Site to ABT Go, ABT Go disconnects the ABT Site network and establishes a direct connection to the selected device using the same adapter.

Video

Both applications use separate adapters:

ABT Site identifies the devices available on its network adapter. After making a connection from ABT Site to ABT Go, ABT Go establishes a connection to the device using a different network adapter, such as Wi-Fi that is different from ABT Site’s connection.

Video

Both applications use a single adapter set on multiple IPs:

ABT Site connects via one of the adapter’s IP addresses. ABT Go scans all IP addresses on the adapter and selects the one matching the device’s network and when the IP address is found, ABT Go opens the device details page without disrupting ABT Site’s connection.

1) Additional information required for Clear device and Clear application commands

Clear device and Clear application can be triggered by various clients, such as ABT Site, ABT Go, Web Interface, provided the operator has the required login credentials. In addition to that, the Clear device command can also be triggered directly on the device, using a specific power cycle/reboot process. With certain families of devices, such as Desigo Control Point, additional information on loaded libraries and templates is required.

 

To all Desigo device families (Desigo room automation, PXC4/5/7, Web Interface, Desigo Control Point, AX100), the following applies:

  • Creare device resets the device to its factory settings. This command deletes all:
    • Loaded applications (control programs, data points, BACnet objects)
    • All field devices on local field networks (such as TX I/O modules, onboard IO configurations, PL-Link/ DALI/Modbus devices)
    • All network settings
    • All loaded certificates
    • The entire control program
    • The grace period is again valid for 35 days

The currently loaded firmware remains on the device, as the factory-set firmware has been overwritten.

 

  • Clear application deletes all loaded applications. This includes:
    • Control programs
    • Data points (and other building automation objects, such as scheduler, value objects, functional SVO)
    • Local field networks (such as TX I/O modules, onboard IO configurations, PL-Link/ DALI/Modbus devices)
    • The grace period is again valid for 35 days

 

Information for Desigo Control Point only

With Desigo Control Point, the FIN-Database is reset.

  • In contrast to Clear device, the command Clear application leaves the following on the device:
    • All network settings
    • All loaded certificates
    • Entire control program

As a result, the device can still be addressed via BACnet and configured routing functions (such as MS/TP field network with PXC7) stay intact. AX100 does not support this function.
