③Toolbar

Command

Description

State

Indicates the state of the application. The green color indicates that the application is online and running or paused.

  • Gray: Engineering session not active, Not connected
  • Green: Application running
  • Orange: Download required
  • Red: Download in progress, Backup in progress or Busy

Check

Checks for duplicate names, number of I/Os, trend limits, etc. The check is automatically performed before loading a device.
Showing data point limits when compiling

(Play)

Only visible when the device is online. Activates an online session and loads changes for the selected device.
Using play/pause function

(Pause)

Only visible when the device is online and an online, session is started. Deactivates an active online session.

 (Alarming)

Temporarily suppresses all alarms for testing purposes.
Suppressing alarms during commissioning or maintenance

Note: If several alarms are triggered due to a field device status is “Device-Missing” (perform an alarm shower), only the “Device-Missing” alarm is sent to the corresponding recipients. This ensures that the user does not receive and have to acknowledge multiple alarms.

Context menu

Command

Description

Add data point

Opens the Add data point window where you can create a new data point.

Delete

Deletes the selected object.

Rename

Opens the Rename device window where you can change the name and description of the selected object.

Duplicate

Creates a copy of the selected object.

Start tracing

Only available when online. Opens the Traces –Network view window where you can view transmitted and received Modbus telegrams with date and time stamp.

Note: The Modbus tracing is not available through MS/TP devices. It is available for MS/TP devices when connected via the WLAN since we have no bandwidth restriction there.

Stop tracing

Only available when Modbus tracing is enabled. Disables the Modbus network tracing.

Optimize network traffic

Applies a bulk reader which reduces the number of requests on the network with the result of reducing the network load.

Shift data point addresses

The address range can be changed by the entered offset for the entire automation station.

Show objects from bulk read

Applies the Assign bulk filter for the selected bulk reader. A bulk reader object has to be selected.

Show in plant

Opens the selected object in the plant view.

Show in program

Opens the Programming editor.

Open properties

Opens the properties of the selected object.

⑤ Library and Properties

The Library and Properties area on the right can be toggled. The Library view contains elements which can be dragged directly to the working area.
Library

The Property view shows the properties of the selected element. The items displayed in the Property view depend on the selected object type.
