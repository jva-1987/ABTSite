Adapting RDG2 device chart of a room

  1. A central function plant with Central operating mode [CenOpMod24] and Central seasonal compensation [CenSsnCmp24] is available in the plant.
  2. Go to Building > Building structure.
  3. Right-click a device and select Go to engineering.
  4. Open the KNX PL-Link task.
  5. In the KNX PL-Link area, select a device (room).
  6. Right-click and select Show in program.
  7. The Programming editor opens.
  8. In the Project tree, select a device chart, for example, [Room name] > Resources > KNX PL-Link > [Room name] > Device chart.
  9. Modify the device chart control program according to the project requirements.
  10. The I/O data points used are available in the device chart control program and are associated with BACnet objects.
