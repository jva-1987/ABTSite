Creating a diagnostic file for a device

Use this procedure to create a diagnostic file for customer support.

  1. An online connection to the device has been established.
  1. Launch the external web browser inside of the Web interface.
  2. Copy the URL to the clipboard.
  3. Launch a web browser outside of the ABT site environment.
  4. Past the URL into the address bar.
  5. Enter a user name and password.
  6. Select Log in.
  7. Go to the Configuration tab.
  8. Select the Device tab.
  9. Select  and then select Debug.
  11. Select Save in the Current diagnostic area.
  12. The diagnostic file is downloaded to the Download folder of the computer.

File format:

  • <%Y%m%d_%H%M%S>_<hostname>_<model_name>_diganostics.tar
  • For example, 20250228_081520_AS3001_PXC7.E400L_diagnostics.tar
