Building structure

The Building structure task allows you to structure the content of a building according to your project. It offers a number of elements (buildings and building elements) to do so. The default names of building structure elements are set in Settings > Naming defaults > Object names.

Add building element


Adds a new building element (e.g. floor) to the end of the list. Select Root in order to add the building element on the top level of the hierarchy. You can select the following building elements:

  • Building
  • Floor
  • Area
  • Subarea
  • Section
  • Global area
  • Plant

Click the arrow next to the button to enter the number of elements to be added.

Status information of a device :

  • defined as BACnet/SC or BACnet MS/TP router
    MS/TP routing
  • Device update is required
  • defined as BBMD device

  • defined as supervision device
    Details tab > Supervision

    Pack & Go workflow

Unplaced rooms: Lists areas without a location. Unplaced rooms can be moved into the building structure.

Unplaced devices: Lists devices without a location. Unplaced devices can be moved into the building structure.

Unused devices: Lists devices, containing only unplaced areas. If an unused device is moved into the building structure, all containing areas are placed in the same building element.

Unassigned room segments: Lists room segments without a present room.

Freely programmable automation stations: Lists automation stations created in ABT Pro without a link into the building structure. To be visible in ABT Site, the automation stations must be saved and compiled in ABT Pro.
Freely programmable automation stations are read-only. They can be assigned to the building structure in ABT Pro.

Go to configuration

Opens Configuration > Application configuration where you can reconfigure the selected application template.

Note
In case of changing an already downloaded template: All configured and commissioned data in the online system are overwritten. To prevent data loss, read back the online system data to ABT Site before making offline changes in the template.
