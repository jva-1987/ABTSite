Create reports

  1. Launch the Connect ABT to BOS application.
  2. Go to Server > BOS reports.
  3. The BOS Reports Wizard dialog box displays.
  5. You can see two tabs, one for Open Existing Report and Configure New Report.
  6. Under the Configure New Report tab, click on each type of report to see the description of the report in the Report Information field.
  7. Select the type of report and click Next.
  8. Select the available project and click Add.
  9. Click Next.
  10. Select the user and click Add.
  11. Click Next.
  12. Select the details and sub-details.
  13. To save the report, click Save Report.
    • Add the Report Name and Report Description and click Save.
  14. To create a report, click Create Report.
  15. The BOS Report window displays the report output.
  16. (Optional) Export reports, Print reports, Additional procedures.
