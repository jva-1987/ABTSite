Application permissions

The administrators have the rights to define user roles and assign user groups.

Item

Description

User

A user can be assigned to various groups and roles.

User group

A group can contain various users and roles.

Role

A role can exist in various groups and can be assigned to various users.

Permission

  • Rights/actions (e.g. check-in) are assigned directly to a role, i.e. they cannot be assigned to a user directly.
  • A role may contain various permissions; a permission may be assigned to various roles. All permissions are inherited to subordinate nodes.
  • If a special permission is required, it can be assigned specific to a folder or project.
