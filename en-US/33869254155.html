Uninstall Connect ABT to BOS

  1. For a new installation, copy the ABTBos.exe file from the common server location to your machine.
  1. Double-click the ABTBos.exe file to start the installer.
  2. The Connect ABT to BOS window displays.
  4. Click Uninstall.
  5. The progress bar displays.
  6. The Uninstallation Successfully Completed message displays.
  8. Click Close.
