Light dimming sensor basic (LDSB)

Property

Description

Default value

LDSB mode

LDSB mode defines if 1 or 2 pushbuttons are used for switching or dimming and defines the behavior of the pushbuttons.

The assortment of available selections depends on the device type.

Switching & dimming: 1 pushbutton is used. A short key press toggles between switching the light on or off. A long key press toggles between dimming the lights up or down.

On & dimming up: 1 pushbutton is used. A short key press switches the light on and a long key press dims the light up.

Off & dimming down: 1 pushbutton is used. A short key press switches the light off and a long key press dims the light down.

2 buttons, switching & dimming: 2 pushbuttons are used. One of the buttons switches the light on or dims the light up the other switches the light off or dims the light down.

Depends on the device type.

Time long key press

Time long key press defines how long a pushbutton has to be pressed to be detected as a long key press.

Range: 3...70 [0.1 s]

Shutter and sunblind sensor basic (SSSB)

Property

Description

Default value

SSSB mode

SSSB mode defines the number of buttons used and the associated moving behavior:

The assortment of available selections depends on the device type.

2-button-mode: One button moves the bind up. The other button moves the blind down.

1-button-mode (Invert MoveUpDown): Pressing the button toggles between moving the blind up or down.

1-button-mode (MoveUp/StepUp): A short key press opens the slats in steps. A long key press opens the slats and then moves the blind up.

1-button-mode (MoveDown/StepDown): A short key press closes the slats in steps. A long key press closes the slats and then moves the blind down.

Depends on the device type

General purpose digital input (GPDI)

Property

Description

Default value

Power return mode

Power return mode defines the behavior of the sensor when power returns after a power failure or when the application is restarted.

never sending after powerup: The sensor does not send a process value to the automation station when it is restarted.

send always after powerup: The sensor sends a process value to the automation station when it is restarted.

if value has changed: The sensor sends a process value to the automation station if the process value after the restart is different from the last process value before power failure.

never sending after powerup

: Process value is not sent spontaneously.

: Process value is sent at regular intervals.

: Process value is sent at regular intervals.
