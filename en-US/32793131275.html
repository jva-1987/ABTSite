Adapting the RDG2 outside air temperature indication

In order for the outside air temperature to be displayed on the RDG2 devices, a small program structure must be created in the control program. This control program must not be created in a device chart under any circumstances, as otherwise the other outside air temperatures will not be connected automatically.

Preparation of the control program

  1. The configuration for displaying the outside temperature on the RDG2 device is activated.
    Configuring an RDG2 outside air temperature indication
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the KNX PL-Link task.
  4. In the Plants navigation view, select a plant with an outside air temperature.
  5. Right-click and select Show in program.
  6. The Programming editor opens.
  7. In the Project tree, select a control program, for example, central function.
    Note: Do not use the device chart program of a room.
  8. Right-click and select Open.
  9. The control program opens.
  10. In the Project tree, select an Outside air temperature.
  11. Drag the Outside air temperature to the control program.
  12. In the Project tree, select a [Room] > Resources > KNX PL-Link.
  13. Drag the Outside air temp.for room op unit to the control program.

Connecting the function blocks

  1. Drag the Outside air temperature FB PrVal output pin to the target Outside air temp.for room op unit FB Val input pin to create a connection.
  3. Select the Outside air temp.for room op unit FB.
  4. Do the following:
    • In the function block pane, select the Interface task.
    • Select the EnWrit property and select the Visible check box.
  6. Drag the Outside air temperature FB Dstb output pin to the target Outside air temp.for room op unit FB EnWrit input pin to create a connection.
  8. Do the following:
    • Select the create connection.
    • Right-click the connection and select Negate.
      Note: This connection ensures that only valid values are sent to the external temperature of the RDG2 device.
  1. By distributing the outside air temperature in the control program, this information can be displayed on every RDG2 device.
