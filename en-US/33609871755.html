Connecting to ABT Go

Use this procedure to launch ABT Go on a configured device. Launches ABT Go (Windows only) on devices discovered in ABT Site.
Configure and download

Only one ABT Go window instance can be opened at a time through ABT Site.

Supported only for device types:

  • DXR1.E
  • DXR2.E/PXC3.E
  • PXC4.E/PXC5.E/PXC7.E
  • EV100E

This functionality does not support:
- MSTP devices
- BACnet/SC connection
- USB connection
- Devices connected via BBMD

  1. The network interface card on the laptop is configured.
    Configuring a network connection
  2. The LAN cable from the commissioning laptop is connected to the network or a USB cable is directly connected to the device.
    Connection types and network card settings
  3. If connected through the room unit, wait for the device to restart after a download (15 to 30 seconds).
  4. ABT Go Windows (same or higher version than ABT Site) must be installed.
  1. Choose one of the adapter configurations:
    • Both applications use a single adapter (Video).
    • Both applications use separate adapters (Video).
    • Both applications use a single adapter set on multiple IPs (Video).
  2. Select Startup > Configure and download.
  3. Select a discovered device in the Discovered devices tab.
  4. Right-click and select Go to ABT Go.
  5. Enter your login credentials if prompted.
  1. ABT Go displays on the device.
