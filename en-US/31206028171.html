Modifying a schedule

This section outlines the following procedures for modifying a schedule:

  • Adding a switching point
  • Using the expanded modification controls
    • Modifying the time
    • Deleting a switching point
    • Changing the current value or setting
    • Returning an object to the schedule default

Adding a switching point

Use this procedure to add a new change of value or setting to the schedule.

  1. While in Edit mode, select the day and time when the switching point is needed.
  2. A new switching point displays.
  3. Enter or select the value of the switching point.
  4. Select Save to save the new switching point.

Note: Cancel discards all changes since the last save.

Select the switching point and select the value to open the modification controls. Enter a new value (analog object) or select a new setting (binary or multistate object). For analog objects, the minimum / maximum range for the object displays above this field.
Select Save.

Return to default

Select Return to default to return the object to the Schedule default.
