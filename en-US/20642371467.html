Adding a BACnet reference to the programming editor

This task will create a BACnet reference object.

Add a BACnet reference from the BACnet reference task

  1. The Programming editor is open.
  2. A BACnet reference object of an EDE object is created.
    EDE file description
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the BACnet references task.
  4. In the Plants navigation view, select a BACnet reference object.
  5. Open the control program.
  6. Drag the BACnet object into the control program of the Programming editor.
  1. A BACnet reference in the control program is created.
