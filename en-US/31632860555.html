Set up an user account

Siemens users and external users receive an email to set up the BOS account.

Setting up an account - Method 1 (Siemens users)

  1. You receive an invitation email to set up BOS account.
  1. Go to the email and click Start using ABT BOS POC.
  3. An external link https://sp.login.siemens.com/ opens.
  4. Click Log In.
  5. The Log in window displays.
  7. Enter your email address and password to finish setting up the account.
  1. The Siemens user account is set up on Siemens portal.

Setting up an account - Method 2 (external users)

  1. You receive an invitation email to set up a BOS account.
  1. Go to the email and click Set password and login.
  3. An external link opens in a new tab.
  4. Enter a new password in the New password and Re-enter password fields and click Reset password.
    For password reset, see Password recovery workflow (external users).
  6. An external link https://sp.login.siemens.com/ opens.
  7. Click Log In.
  8. The Log in window displays.
  10. Enter your email address and password to finish setting up the account.
  1. The Siemens user account is set up on Siemens portal.
