LgtIn

The following tables show the properties for the channel configuration of lighting inputs (LgtIn) without any subsystem-specific extension.

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the data point "BIL" is selected in the Device view tab.

Number of channels

"Number of channels" defines how many channels are used by the data point.

If more than one channel is used by the I/O data point, all properties are stored in the first channel.

Signal type

"Signal type" defines the DRA signal type. Available signal types depend on I/O module type. The signal type can be edited.

Pulse length

"Pulse length" defines how long a pushbutton has to be pressed to be detected as a long pulse.

Range 0.1…25.5 [s]

Repetition time

"Repetition time" defines the required additional time for a very long pulse as compared to a long pulse.

Range: 0.1…25.5 [s]

Press time twice

"Press time twice" defines the maximum pause time in a double-click.

Range 0.1…25.5 [s]

Toggle enabled

"Toggle enabled" defines if repeatedly pushing the same button switches the light on and off.

No: The button is only used to either switch the light on or off. A button pair is needed for switching on and off.

Yes: Repeatedly pushing the same button switches the light on and off.

Pushbutton events (list)

Enable or disable pushbutton events in the list: The assortment of options depends on the number of channels.

Rising edge

Falling edge, press long

Falling edge, press 2x, long

Repeat cyclic

Press 2x, briefly

Press 2x, long

Press two-buttons

Pushbutton events (table)

Defines pushbutton events.

  • Pushbutton event (from list)
  • Action: Operation associated with the pushbutton event: Stop, Dimming up, Dimming down, Step up, Step down, Switch on, Switch off, Go to level, User defined 1...5, No action.
  • Level (%). Range: 00.0...100.0 [%]
  • Step increment (%). Range: 00.0...100.0 [%]

Save as

"Save as" saves the set parameters of the I/O data point as an xml-file.
