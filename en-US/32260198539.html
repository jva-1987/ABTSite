Configuring WAN settings

Allows the verification and configuration of a WAN network in a Desigo system.

 

Setting

Description

Configure IPv4

DHCP: Use dynamic IP addressing.

Manual: Use a fixed IP address. Complete the IPv4, Subnet mask and Router fields.

IPv4

IPv4 address of the device.

Subnet mask

Specifies the subnet within the larger network.

Router

Specifies a node on a TCP/IP network that serves as an access point to another network.

MAC address

(Information only) MAC address of the device.

DNS server

Preferred DNS server.

Device name on IP

Allows you to change the device name online.

Local UDP port

UDP port number that the service uses to communicate. Range is 0–65535. Default: 47808 (BAC0).
