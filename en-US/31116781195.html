Network tab

 

1

IPv4

  • Displays the detailed settings for the IPv4 network.

2

WAN

  • Displays the detailed settings for the WAN network.

3

Physical ports

  • Displays the status of the physical ports of the Desigo devices.

4

Discard changes

  • Resets the changes that have not yet been saved.

5

Apply changes

  • Saves all the changes within this dialog to the Desigo device immediately.
    Note    : Changes do not have to be additionally confirmed with Activate changes.

6

Number of changes

  • Displays the number of unsaved changes.

7

Property area

  • Displays the properties for the selected tab.
