Working with the device information

This information can be accessed using BACnet services like ReadProperty, ReadPropertyMultiple, or Who-Is/I-Am services. The key information can be obtained from a BACnet device:

  • Basic device information
  • Object information
  • Service information
  • Network information
  • COV subscriptions
  • Time synchronization
  • Change date and time

The following topics are listed under the event handling section:

  • Enabling and analyzing event history
  • Enabling and analyzing event log history
  • Enabling and analyzing commissioning history
