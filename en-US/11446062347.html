QMX2.P33, P43 template properties

The listed properties are displayed in the QMX2 templates editor > Inspector window > Properties tab when the templates is selected in the Project tree.

Marked properties ( 1) , 2) ) belong to a subsystem-specific extension. If the corresponding subsystem-specific extension is enabled, it overwrites the selected QMX2 template properties. As a precondition the property in the QMX2 template must be enabled.
