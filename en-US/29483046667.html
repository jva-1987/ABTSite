Offline activation/deactivation

This workflow must always be used if a computer is not connected to the Internet for critical environments.

 

1. Working on premise with ABT Site offline

  1. A virus-free computer with ABT Site installed is provided by the customer.
  2. The ABT Site computer is not connected to the Internet.
  1. Create a project with the building hierarchy and its devices.
  2. Create the control program as usual.
  3. Go online and read back the serial number.

 

2. Assigning the license to the device

  1. The LMS license activation ID for the device is available.
  1. Go to Building > Building structure.
  2. Select the device.
  3. Select the Embedded license tab.
  4. Copy the Activation ID from the LMS license into the clipboard.
  5. Paste the activation ID in the Activation ID field.

    Note: If the serial number of the device is not available, the activation ID can be added but not activated. Connect to the device and upload the serial number to complete the license activation process. The Status Not activated displays. Without the serial number, the export function cannot be used.
  6. Click OK.
  7. The license is successfully assigned but not activated yet.

 

3. Exporting licenses from ABT Site offline

  1. Go to Building > Building structure.
  2. Select a building hierarchy object.
  3. Right-click and select Licensing > Export embedded licensing information for the project.
  4. The Export embedded licensing information dialog box opens.
  5. Select Open folder.
  6. The myProject.s1ele license file is exported.
  7. Save the myProject.s1ele file on a transportable storage medium.

 

4. Activating the license on an Internet computer

  1. ABT Site is installed and an Internet connection is available.
  2. The myProject.s1ele file is stored on this computer.
  1. Select the myProject.s1ele file from the file explorer.
  2. Double-click the myProject.s1ele file to start the online registration process.
  3. The registration process is finished when the myProject.processed.s1ele file is created.
  4. Copy the new the myProject.processed.s1ele file with the license registration to transportable storage medium.

5. Importing license into ABT Site offline

  1. The myProject.processed.s1ele file (after license registration) is available and the virus check has been completed.
  1. Go to Building > Building structure.
  2. Select a building hierarchy object.
  3. Right-click and select Licensing > Import embedded licensing information for the project.
  4. Select the myProject.processed.s1ele file.
  5. Select Open.
  6. The license file is imported and ready to use.
  7. Go to Startup > Configure and download.
  8. In the Engineered devices tab, right-click a device that matches a discovered device.
  9. Select Load and then Full (device may restart).
  10. The license is downloaded and operable.
