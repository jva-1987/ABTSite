In-/output properties

The list of BACnet object properties is listed in alphabetical order.

✳ Indicates a Siemens proprietary property.

Acknowledged transitions

 

 

"Acknowledged transitions" conveys three flags that separately indicate the receipt of acknowledgments for TO-OFFNORMAL, TO-FAULT and TO-NORMAL events. These flags is cleared upon the occurrence of the corresponding event and set under any of these conditions:

  • Upon receipt of the corresponding acknowledgment;
  • Upon the occurrence of the event if the corresponding flag is not set in the "Event enable" property (meaning event notifications will not be generated for this condition and thus no acknowledgment is expected);
  • Upon the occurrence of the event if the corresponding flag is set in the "Event enable" property and the corresponding flag in the "Acknowledgement required" property of the "Notification class" object implicitly referenced by the "Notification class" property of this object is not set (meaning no acknowledgment is expected).

Acknowledgement credentials

 

 

"Acknowledgement credentials" consisting of three character strings identifying the user or process that acknowledged the most recent TO-OFFNORMAL, TO-FAULT, and TO-NORMAL event notifications.

Active text

 

 

'Active text' describes the active state of property 'Present value'.

BACnet clients and devices can dynamically discover the available properties of a BACnet object, without needing to have prior knowledge of the object's specific implementation or type.

Activate substitute value ✳

 

 

"Activate substitute value" refers to a BA object property which defines the behavior of the BA input object.

  • to initialize present value and update count value at startup:
    - if Activate substitute value = False and Out of service = False, then present value = default value
    - if Activate substitute value = True and Out of service = False, then present value = Substitution value
  • to update present value at runtime if Reliability ≠ ‘no-fault’
    - if Activate substitute value = False, then present value is unchanged
    - if Activate substitute value = True, then present value = Substitution value

Event configuration ✳

 

 

"Event configuration" property in BACnet refers to the configuration of event-related properties for a BACnet object. Some key event configuration properties in BACnet include:

  • Event_Type: Specifies the type of event, such as change-of-value, change-of-state, or alarm.
  • Notification_Class: Specifies the notification class associated with the event, which determines how the event notification is handled.
  • Event_Enable: Specifies which event transitions (to-offnormal, to-fault, to-normal) are monitored and reported.
  • Acked_Transitions: Specifies which event transitions have been acknowledged.
  • Notify_Type: Specifies whether the event notification is an alarm or a simple event.
  • Event_Time_Stamps: Records the time stamps for event-related state changes.
  • Event_Parameters: Stores the parameters specific to the event type, such as limit values or state change values.

Out of service

 

 

"Out of service" allows decoupling the object from being modified by a control program, system program or peripheral device.

  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" will no longer be updated by the respective control program, system program or peripheral device.
  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" can be modified for simulating and testing purposes.
  • If "Out of service" will be changed from FALSE to TRUE, the properties "Present value" and "Reliability" keep their values. Nevertheless, they can be individually modified afterwards.
  • If "Out of service" will be changed from TRUE to FALSE, the properties "Present value" and "Reliability" keep their values. They will be modified by the next update of the producer.

Property ID: 84

Present command priority

 

 

'Present command priority' property in BACnet refers to the priority level associated with the current command being sent to an object. In BACnet, commands can be sent to objects at different priority levels, ranging from 1 (the highest priority) to 16 (the lowest priority). The Present command priority property indicates the priority level of the most recent command that has been issued to the object.

The purpose of the priority levels is to allow different systems or users to have different levels of control over an object. For example:

  • A high-priority command (e.g. priority 1) might come from a safety system that needs to override all other commands to ensure the system is in a safe state.
  • A medium-priority command (e.g. priority 8) might come from a building automation system that is managing the normal operation of the equipment.
  • A low-priority command (e.g. priority 16) might come from a user interface that allows occupants to make minor adjustments.

Present maximum value ✳

 

 

The object's "Present value" is limited to the range maximum. Values outside a configured "Present maximum value" will be rejected by the system and no change will be made to the "Present value". If the object is placed "Out of service", attempts to command the "Present value" to a value outside the maximum range will be rejected and the current "Present value" will remain unchanged.

Present minimum value ✳

 

 

The object’s "Present value" is limited to the range minimum. Values outside a configured "Present minimum value" will be rejected by the system and no change will be made to the "Present value". If the object is placed "Out of service", attempts to command the "Present value" to a value outside the minimum range will be rejected and the current "Present value" will remain unchanged.

Resolution

 

 

'Resolution' indicates the accuracy of a value. It defines the smallest detectable change in engineering units of the 'Present value' property and can be changed online.

'Resolution' is typically used for operating and monitoring functions to represent the 'Present value' in an appropriate way. A value of 16.3434 °C is displayed as 16 °C when the resolution = 1, as 16.3 °C when the resolution = 0.1, and as 16.34 °C when the resolution = 0.01.

'Resolution' is only used for an abbreviated depiction on the display, e.g., a station for operating and monitoring. It is not used to shorten the actual value processed by the program.
