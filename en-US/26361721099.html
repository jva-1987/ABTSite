Export report folder

Log on to the Connect ABT to BOS application. See Sign in and connect to BOS server.

  • Exported reports are available in this location.

 

  1. Log on to the Connect ABT to BOS application. See Sign in and connect to BOS server.
  1. Go to Tools > Options.
  2. In the General Options, go to the Export report folder.
  3. Open ABT Site, and go to Settings > Projects and paths, and copy the path in the Use absolute path field.
  5. Click Browse, and select the same project path as in ABT Site.
  1. You have set the export report folder path for BOS.
