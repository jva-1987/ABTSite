Adapting the RDG2 operating mode

A central operating mode control is a function that enables the operating modes of multiple devices or systems to be controlled and coordinated centrally. Operating mode changes can be programmed and automated via the central interface. For example, the system can automatically switch to “Heating” mode in the morning and “Ventilation” mode in the evening, even if the room control unit specifies a different operating mode.

  1. The Central operating mode is available.
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the KNX PL-Link task.
  4. In the KNX PL-Link area, select a device (room).
  5. Right-click and select Show in program.
  6. The Programming editor opens.
  7. In the Project tree, select [Room name] > Resources > KNX PL-Link > [Room name].
  8. Select the Device chart.
  9. Right-click and select Open.
  10. The device chart opens.
  11. In the Project tree, select [Central function] > BACnet > Central operating mode.
  12. Drag the Present op.mode for room to the PrOpModR FB.

The behavior of “OpMod” and “OpModMan” in the RDG2 device chart is as follows:

- “OpMod” is used to specify the operating mode of the RDG2 from an external scheduler (internal RDG scheduler is overwritten).

- “OpModMan” has higher priority than “OpMod”. However, if “OpModMan” is set to auto, “OpMod” determines the RDG2 operating mode if it is used/activated.

- “OpModMan” is used to manually set the local operating mode of the RDG2 (internal scheduler is overwritten). The relative setpoint adjustment continues to function if it is not blocked by the RDG2 internal setting.
