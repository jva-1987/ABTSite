Search history of project/user details

  1. Go to Server View.
  2. From the Server menu, select History.
  3. The Source Control History dialog box displays.
  4. Enter the user details in the User field to search information about the user and click Search.
  5. You can see the search results filtered in the field below.
  6. In the Operations section, select the different operation criteria by clicking on any of the given options and then click Search.
  7. The results display in the output pane as message logs.
