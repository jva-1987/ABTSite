Common options

To view the general BOS settings, go to Tools > Options or click on Settings in the Application pane.
See Define settings.

Local project folder path

Use this folder to create a folder structure to store your BOS projects.

We recommend keeping the same path as the ABT project path.

Export report folder path

Store your export files for your local projects in this path.

Display order

Set the display order as Firstname Lastname or Lastname, Firstname.

Language

Select the language from the drop-down list.

Connection speed

Always select the connection speed as Fast (LAN).
