Adapting the RDG2 green leaf trigger

General green leaf behavior

The green leaf icon on the RDG2 device usually indicates that a particular function or setting has a positive impact on the energy efficiency and sustainability of the room. It indicates that a room is running in a sustainable operating mode, for example, with reduced power or optimized control. If the green leaf changes to red, the control chain and the current operating mode must be checked.

Green leaf functionality between PXC4/5/7 and RDG2 device

The green leaf display on the RDG2 device is calculated based on room conditions. There is no direct control from the PXC4/5/7 control program to the green leaf display on the RDG2 device. However, the green leaf trigger function can be used to ensure that all RDG2 devices in a building display the green leaf status. This typically occurs once per day.

  1. The Central operating mode is available.
  2. The BACnet object Trigger green leaf command is created.
    Configuring an RDG2 green leaf trigger command
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the KNX PL-Link task.
  4. In the KNX PL-Link area, select a device (room).
  5. Right-click and select Show in program.
  6. The Programming editor opens.
  7. In the Project tree, select [Room name] > Resources > KNX PL-Link > [Room name].
  8. Select the Device chart.
  9. Right-click and select Open.
  10. The device chart opens.
  11. In the Project tree, select [Central function] > BACnet > Central operating mode.
  12. Drag the Present op.mode for room to the REeiRst FB.
