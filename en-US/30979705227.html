Changing text on the landing page

Use this procedure to update the landing page with a customer-specific text.

  • A customer text is not overwritten during a firmware update, full load, delta load and clear application.
  • The customer text is overwritten during a clear device or when uploading the device to ABT Site as a new device.
  1. You are logged in as an administrator.
  1. Go to the Configuration tab.
  2. Select the Device tab.
  3. Select  and then select Change landing page.
  5. Enter the desired customer text in the text field. Up to 500 characters can be entered. The input will only accept plain text without any formatting.
    Note: If the text field is empty, the default text will be shown on the landing page.
  7. Select Save.
  8. Repeat these steps for all devices.
