Replacing a device

  1. The damaged device must be replaced.
  2. The LMS license of the damaged device is available.
    Note: If no license is available, the device can be operated during the "grace period".
  1. Replace the damaged device of the same device type in the cabinet.
  2. Download the control program with ABT Site to the replaced device.
    Downloading a control program to a device
  3. Upload the serial number from the replaced device.
    Uploading a device configuration
  4. Go to Building > Building structure.
  5. Select the device and check if the serial number of the replaced device is available or take the serial number from the existing ABT Site entry.
  6. Select the Embedded license tab.
  7. Copy the Activation ID from the LMS license file into the clipboard.
  8. Paste the activation ID in the Activation ID field.
  9. Click OK.
  10. The license is successfully activated but not loaded to the device yet.
  11. Go to Startup > Configure and download.
  12. In the Engineered devices tab, right-click a device that matches a discovered device.
  13. Select Load and then Full (device may restart).
  1. The license is downloaded to the replaced device.
