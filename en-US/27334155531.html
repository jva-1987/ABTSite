Adding a license

  1. The Desigo device version is ≥ 1.8. In the Details pane, select the System tab for verification.
    Details tab > System
  2. The device type is PXC5.E003.
  3. The LMS license activation ID for the device is available.
  1. Go to Building > Building structure.
  2. Select the device.
  3. Select the Embedded license tab.
  4. Copy the Activation ID from the LMS (License Management System) license file into the clipboard.
  5. Paste the activation ID in the Activation ID field.

    Note: If the serial number of the device is not available, the activation ID can be added but not activated. The Status Not activated displays.
  6. Click OK.
  7. The license is successfully added but not activated for the device yet.
    Activating a license
    Connect to the device and upload the serial number to complete the license activation process.

NOTICE

Replace defective device

Avoid ordering a new license

  1. If a device has to be replaced in the event of a defect, the license can be reused for the new device. For this reason, you should keep the license files in a safe place.
