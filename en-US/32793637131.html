Configuring an RDG2 operation for room unit and fan mode

The RDG2 can monitor various environmental parameters, such as temperature, humidity, air pressure and fan speed, and provide alarms or notifications if the conditions fall outside the specified ranges.

Configure the room operator selector

  1. An RDG2 KNX PL-Link device is added.
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the KNX PL-Link task.
  4. In the KNX PL-Link area, select the device.
  5. Select the Configuration tab on the right.
  6. The Configuration view shows the properties of the selected device feature.
  7. In the Name column, select Service parameters > P002: Operation, room operating mode selector.
  8. In the drop-down list, select an option:
  9. Auto / Protection
  10. Auto / Cmf / Eco / Prot
  11. Hospitality auto / protection

Configure the fan mode selector

The RDG2 fan mode selector provides the user with the flexibility to choose the appropriate fan mode based on the specific requirements of the room where it is being operated, ensuring the desired air circulation and environmental conditions are maintained.

  1. In the KNX PL-Link area, select the device.
  2. Select the Configuration tab on the right.
  3. The Configuration view shows the properties of the selected device feature.
  4. In the Name column, select Service parameters > P003: Operation, fan mode selector.
  5. In the drop-down list, select an option:
  6. Auto / Manual
  7. Manual
  8. Auto / Manual / Protection
  9. Auto / Protection
