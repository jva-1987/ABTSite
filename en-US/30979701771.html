About Web interface

This manual provides an overview of the Web interface for managing your building control. It is primarily aimed at commissioning engineers who are not yet familiar with the BACnet hierarchies and the Siemens standard solutions.

What is the Web interface

The Desigo Web interface allows users to access and interact with the Desigo system through a standard web browser, without the need for specialized client software. This provides a flexible and platform-independent way to monitor and control the Desigo building automation system.

  • The Web interface serves as a centralized access point for managing and monitoring the various components of the Desigo system, including controllers, field devices, and BACnet objects.
  • The Web interface provides real-time monitoring of the Desigo system, displaying key performance indicators, alarms, and other relevant data.
  • Users can view the current status of the system, including temperatures, setpoints, and equipment operations.
  • The Web interface allows users to view, acknowledge, and manage alarms and events generated by the Desigo system.
  • The Web interface offers reporting and analytics capabilities, allowing users to generate custom reports, trend data, and analyze the performance of the building automation system.

Documentation content

It contains the following sections:

  • Overview provides a high-level overview of the user interface, main menu and status bar, settings, events and manual overrides.
  • Object view provides an overview of the work area, an outline of icons, state indicators, and procedures for commanding properties.
  • Configuration provides an overview of submenus, navigating, viewing, and engineering different areas of your device.
  • Workflows for basic configurations and operating.
  • Workflow for expert users.
  • Restrictions on using Web interface.
  • BACnet properties of in- and output objects and the device object.

Depending on the device type, firmware version, ABT site version or engineered application, not all documented functions may be available in the Web interface.
