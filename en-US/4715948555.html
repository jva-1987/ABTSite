SHD_PAR1: Shading parameter 1, energy efficiency

Block SHD_PAR1 (FB800) includes a set of parameter values. These parameter values are used in the charts for automating shading applications, e.g. {ShdEngyEffcy01}.

Functioning

The block can be parameterized and provide parameter values.
