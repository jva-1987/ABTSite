Glossary

APDU

APDU stands for Application Protocol Data Unit, which is a communication protocol used between a smart card and a card reader. It is a simple and standardized format used to send and receive data between the two devices.

BACnet/SC

BACnet/SC (BACnet Secure Connect) is a security extension to the BACnet building automation protocol that introduces the use of digital certificates for secure communication. This ensures the confidentiality of the data exchanged between the devices, protecting it from eavesdropping and tampering.

BBMD

BBMD stands for BACnet Broadcast Management Device. It is a component used in BACnet systems to manage the routing of broadcast messages across different BACnet networks. BBMDs are an essential component in large-scale BACnet systems that span multiple networks or subnets.

BDT

BDT stands for Broadcast Distribution Table, and it is a key component in BACnet systems that utilize BACnet Broadcast Management Devices (BBMDs). The BDT is used by the BBMD to determine how to route BACnet broadcast messages between different BACnet networks. When a BBMD receives a broadcast message, it consults the BDT to identify the appropriate destination BBMDs and forwards the message accordingly.

Canadian units

The Canadian system of measurement primarily uses a combination of the metric system (International System of Units or SI) and some legacy imperial units

CSV

A CSV (Comma-Separated Values) file is a simple and widely-used file format for storing and exchanging tabular data. It is a text-based format that represents data in a structured way, with each row of data separated by a line break, and each column of data separated by a comma (or another delimiter). Example:Name,Age,City John,25,New York Jane,32,London Bob,41,Paris

DHCP

DHCP stands for Dynamic Host Configuration Protocol. It is a network protocol used to automatically assign IP addresses and other network configuration parameters to devices on a network. This allows devices to join a network without requiring manual configuration of their network settings. When a device connects to the network, it requests an IP address from the DHCP server. The DHCP server then dynamically assigns an available IP address to the device from a predefined pool of addresses.

ECDSA

ECDSA stands for Elliptic Curve Digital Signature Algorithm, it’s used to create a digital signature of data in order to allow you to verify its authenticity without compromising its security.

FQDN

FQDN stands for Fully Qualified Domain Name. It is the complete domain name for a specific computer or device on the internet.For example, the FQDN for the website of Siemens could be: www.siemens.com The key components of an FQDN are: - hostname: The unique name of the specific computer or device, such as "www" or "server1" - domain: The organization or business name, such as "siemens" - top−level−domain: The highest-level domain, such as ".com" or ".org"

IEEE802.1X

IEEE 802.1X is a standard that provides port-based network access control for wired and wireless local area networks (LANs). In the context of IEEE 802.1X, a certificate refers to a digital certificate that is used for authentication and secure communication. IEEE 802.1X certificates are used to establish a secure communication channel between the connecting device and the network access server (e.g., a RADIUS server).

Imperial units

Imperial units refer to the system of measurement that was historically used in the United Kingdom and some of its former colonies, such as the United States, Canada, and Australia.

ISO 3166-1

ISO 3166-1 is the standard that defines the codes for the names of countries, dependent territories, and special areas of geographical interest. It is published by the International Organization for Standardization (ISO).

MS/TP

MS/TP stands for Manager-Subordinate/Token-Passing. It is a communication protocol used in building automation and control systems, particularly in the context of the BACnet standard. The MS/TP protocol is known for its simplicity, reliability, and low-cost implementation, making it a popular choice for building automation applications.

NTP

A NTP (Network Time Protocol) server is a computer or network device that is responsible for providing accurate time synchronization over a network. The main purpose of a NTP server is to ensure that all the devices and systems connected to the network have a consistent and accurate time reference, which is crucial for the applications and operations.

PEM

PEM (Privacy Enhanced Mail) format is a base64-encoded representation of a cryptographic object, such as a certificate, a private key, or a certificate chain. The PEM format is widely supported by various applications and tools that work with digital certificates and cryptographic keys. Filename Extension: PEM files typically have the .pem filename extension, although .crt and .cer are also commonly used for certificate files.

PKI

PKI stands for Public Key Infrastructure. It is a system of digital certificates, Certificate Authorities (CAs), and other registration authorities that verify and authenticate the identities of individuals, computers, and other entities on a network. PKI is an essential component of many secure communication and authentication systems, enabling the reliable and trustworthy exchange of information in a digital environment.

RADIUS

A RADIUS (Remote Authentication Dial-In User Service) server is a network server that provides centralized authentication, authorization, and accounting (AAA) management for users who connect and use a network service.

RSA

RSA (Rivest-Shamir-Adleman) algorithm is an asymmetric or public key cryptography algorithm which means it works on two different keys: Public key and private key. The public key is used for encryption and is known to everyone, while the private key is used for decryption and must be kept secret by the receiver.

SI units

The SI (International System of Units) is the modern standardized metric system of measurement.

TLS

A TLS (Transport Layer Security) certificate is a digital certificate used to establish a secure and encrypted connection between a client (such as a Web browser) and a server (such as a Web server) over the internet.

UDP

UDP ports are used to identify specific applications or services running on a network device. Each UDP port is assigned a unique number between 0 and 65'535, with certain port numbers reserved for specific protocols or applications.

US units

The primary system of measurement used in the United States is the customary or imperial system, which is based on traditional units that originated in the United Kingdom.

UTC

UTC (Coordinated Universal Time) is the primary time standard by which the world regulates clocks and time. It is the basis for civil time and time zones worldwide. For example, New York is UTC-5 (5 hours behind UTC), while Tokyo is UTC+9 (9 hours ahead of UTC).
