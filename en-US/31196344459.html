Assigning devices

Discovering and assigning devices

Use this procedure to discover all devices communicating on the network and assign the desired devices for monitoring.

  1. Go to the Configuration tab.
  2. Select the Assigned devices tab.
  3. Select Discover to trigger a discovery.
  4. A list of all devices communicating on the specified network displays, including the device discovered itself.
  5. Do one of the following:
    • Select Assign for the device(s) you want to monitor.
    • Select Assign all to monitor all devices.
  1. The selected devices are now available for monitoring.

Adjusting the parameters for device discovery

This procedure modifies the properties of device discovery. For example, you can limit the discovery to the local network and a specific range of device numbers.

  1. Select Options to open the filtered properties of Discovered devices.
  2. Use the Options button to select each parameter.
  3. Select Discover.

Setting

Description

Discovery scope

Determines if the device discovery is restricted to the local network or if remote networks are included.

Options: Local network or remote network. If remote network is selected, verify that the network number setting is correct.

Network number

The network number to use for the device discovery.

Min. device instance number

Limits the device discovery to a range of devices.

The minimum value is 1.

Max. device instance number

Limits the device discovery to a range of devices.

The maximum value is 4194302.

3rd party devices

Determines if third-party devices are included in the device discovery.

Select False to exclude third-party devices, or True to include third-party devices.
