Element properties tab

The Element properties tab shows the properties of the selected element. The tab title changes according to the selected element. The items displayed in the Element properties tab depend on the selected element in the Programming editor or Room editor.

Element properties tab > Naming

Setting

Description

Description

The description of the selected element.

Note
The description and the name are linked, i.e., the description matches the name and vice versa. To unlink the description from the name, click the chain icon to the right of the Description and Name fields. To relink the description and the name, click the chain icon again.

Name

The name of the selected element.
Renaming elements

Extension

The naming extension of the selected element.

Click the button next to the Extension field to define the extension rule.

Extension type

Applicable for xFBs, disabled / hidden for charts.

Object naming in chart > Chart name

The full object name.

Element properties tab > Chart

Setting

Description

Protection

Protects the chart from unauthorized changes. You must define an access password.

Read-only

The chart cannot be changed.

Changed

Set to writable or readable when the Read-only checkbox is checked/unchecked.
Charts read-only

Note: This field is empty for the first instance.

Origin

Shows the origin/original location of the chart and timestamp when chart was created.

Version

The version number of the chart. Numeric value in the form "abc.def" (read / write, between "0.0" and "999.999" or empty).

Type

The chart type.

Author

The author of the chart (read / write, max 255 characters).

Library group

The drop-down gives a list of predefined group names to group the content in the Program blocks folder under Library. Library group tags are available only for charts.

Help ID

Help ID for context help of the selected chart. To open the help page for the selected chart, press F1.

Note: Do not change the Help ID of predefined charts, else the context help will not work as expected.

Element properties > Structure

Setting

Description

Show in BACnet

Checkbox to show the corresponding chart on BACnet or removing it from BACnet again. By default, it is unchecked.

Function type

Type of function with text picker and custom text support.

Family

Module family with text picker and custom text support.

Options

Option tag with a list of predefined group names. You can add only one option tag for the chart while you can add multiple options for function blocks and text boxes.

Initial node subtype

Type of function with text picker and custom text support containing only the initial name string.

Define node subtype independent of function type

Checkbox to enable the initial node subtype.

Element properties tab > Block

Setting

Description

BACnet object type

The BACnet object type of the block.

Device instance

The device instance number as an integer.

To change this entry, select BACnet reference (if available) in the BACnet object type field.

Object type

The object type as an integer.

To change this entry, select BACnet reference (if available) in the BACnet object type field.

Object instance

The object instance number as an integer.

To change this entry, select BACnet reference (if available) in the BACnet object type field.

Version

The version number of the block.

Type

The block type.

Author

The author of the block.

Call(type)

The call type of the block.

Copy configuration from BACnet object

Copies the setting of the BACnet object to all "Value" pins of the function block.

  • Analog: Copies the BACnet property "Units" to all "Value" pins of the function block.
  • Multistate: Copies the BACnet property "State Text" to all "Value" pins of the function block.

Element properties tab > Group members

Command

Description

Remove selected

Element properties tab > Configuration

Program blocks are configured by means of BA value objects. The main values of these value objects are listed to provide a configuration functionality on the program block function level.

The following objects are listed for the configuration:

  • Analog config, calc and process values
  • Binary config, calc and process values
  • Multistate config, calc and process values

Setting

Description

Description

The description of the BA value object.

Value

The value of the BA value object.

Unit

The unit of the BA value object.
