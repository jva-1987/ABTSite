Firmware update

  1. An online connection to the device is established.
  1. Launch a web browser outside of the ABT site environment.
  2. Enter http://localhost:50094/om/#/landing/login in the address bar.
  3. Enter a user name and password.
  4. Select Log in.
  5. Go to the Configuration tab.
  6. Select the Device tab.
  7. Select  and then select Firmware update.
  9. Do one of the following to select the firmware:
    • Drag the file into the dialog box.
    • Select Browse files and select a file.
  10. Select Load .
  11. The device restarts after each firmware download. Depending on the device type, this can take > 1 minute.

If  is displayed, the firmware has just been downloaded. From this point on, the device restarts. Unfortunately, the Wait information is not updated so that the end of the device restart is not displayed.
