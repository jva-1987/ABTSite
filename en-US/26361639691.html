Define settings

  1. You have administrator rights.
  2. You have defined users, user groups, and roles via the Security Settings function.
  3. If you have associated permissions, you can assign user and/or user group privileges for certain functions (via roles).
  1. Launch the Connect ABT to BOS application on the desktop.
  2. The Connect ABT to BOS dialog box opens.
  3. Click Yes to set the application paths.

Defining the common options

  1. In the menu bar, go to Tools > Options or click Settings in the Application pane.
  2. Click the General Options button.
  3. In the Local project folder, select Browse.
  4. Select the project path of the ABT Site project.
  5. In the Export report folder, select Browse.
  6. Select a report path to store the created reports.
  7. Click OK.

Defining the shared options

See Sign in and connect to BOS server.

  1. In the menu bar, go to Tools > Options or Settings in the Application pane.
  2. Click the BOS Servers option.
  3. Select the Use Server check box.
  4. To add a new BOS server, click New.
  5. The New BOS Server dialog box opens.
  6. Enter the following information:
  7. In the Name field, enter a freely definable server name.
  8. In the URL field, enter the valid URL to the BOS.
    Examples:
    https://BranchHost
    https://SpecialHost/Path
    https://139.16.94.16/BosWeb
    Note: For security reasons, the server path or URL is provided by the BOS administrator.
  10. (Optional) In the Description field, enter a description for the BOS.
  11. (Optional) Click Test to verify the connection to the BOS server.
  12. Alternatively, you can add a new BOS server using a .config file provided by the administrator.
    • In the New BOS Server dialog box, click Azure.
    • Select the .config file from the local path and click Open.
  14. The Name, URL and Description fields are filled automatically.
  15. Click OK.
  16. The Options dialog box shows the defined server connection.
  17. Click OK.
  18. The Local View environment opens.

To modify and remove the existing BOS server, see Modify and remove existing BOS server.
