Printing active plants

The print option in the toolbar is active for the automation station and allows to print the content of all charts.

  1. Open the programming editor for a plant.
  2. Click the empty chart area.
  3. The print option enables on the toolbar.
  4. Click .
  5. The Print window displays.
  7. Enter the values in the following fields:
    • Select the print format in the Name field.
    • Select the layout of the document in the Document information field and click .
  8. Click Print.
    Note: To view the print preview, see Print preview.
  9. The print runs for a few seconds and the print progress is seen at the bottom right of the window.
  10. A local path opens to save the print document.
  11. Enter a filename and click Save.
  1. The system prints the plant information.
