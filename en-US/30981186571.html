Checking the commissioning state of a data point

  1. Go to the Object view tab.
  2. Select  Application.
  3. Select  [Plant name] > [Object name].
    Note: The data points can be located on different hierarchy levels.
  4. Select .
  5. The Object properties dialog area opens.
  6. Select the Properties tab.
  7. In the Commissioning state drop-down list, select the option:
    • Not checked
    • Failed
    • Passed
  8. Select  to send the command.
  9. Select the next data point.
