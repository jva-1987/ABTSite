Shared search

The search option allows you to search information about a particular project in a simple way.

Search criteria

  • ProjectName
  • ProjectDescription
  • ProjectAuthorName
  • ProjectVersion
  • NodeName
  • NodeDescription
  • NodeType
  • NodeSystemVersion
  • NodeLocationName
  • FolderOrFileName

Search project/user details

  1. Go to Server View.
  2. From the Server menu option, select Shared Search.
  3. The Search On Server dialog box displays.
  4. Under Domain Attributes, from the drop-down menu, select Project name for example.
  5. In the empty field, enter the name of the project that you want to search.
  6. Click Search.
  7. The project displays in the output pane below.
  8. Right-click and select Navigate to the item.
  9. The project is automatically synchronized and takes you to the location of the project under the project tree.
  11. Use Add Search Criteria to add more ways to search an item.
  12. In the Controlled Item Attributes tab, enter the user details in the User field to search information about the user and click Search.
  13. You can see the search results filtered in the field below.
  14. In the Operations section, select the Not Controlled, Checked In or Checked Out projects, by clicking on any of the given options and then click Search.
  15. The results display in the output pane as message logs.
