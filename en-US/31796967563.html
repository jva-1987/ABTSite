Start/stop M-bus

  1. Go to the Object view tab.
  2. Select  Field bus.
  3. Select  M-bus network.
  4. Select  M-bus management.
  5. Select .
  6. The MbusMgmt Details dialog area opens.
  7. Select the Properties tab.
  8. In the Field bus command section, select the Stop button.
  9. The Stop button changes from green to red.
  10. The M-bus field bus is halted.
  11. Select the Reset button.
  12. The Reset button changes from green to red.
  13. The M-bus field bus is running.
