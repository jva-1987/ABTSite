Activating a license

  1. The Desigo device version is ≥ 1.8. In the Details pane, select the System tab for verification.
  2. The device type is PXC5.E003.
  3. The online connection to the device is established.
  4. The serial number of the device is available.
    Uploading a device configuration
  1. Go to Building > Building structure.
  2. Select the device.
  3. Select the Embedded license tab.
  4. Select the license.
    Note: If the serial number of the device is not available, the activation ID can be added but not activated. Connect to the device and upload the serial number (serial numbers can also be added manually or by a barcode scanner) to complete the license activation process. The Not activated status displays.
  5. Select Activate.
  6. The license is successfully activated but not loaded to the device yet.
  7. The Activated status displays.
  8. (Optional) Select the Support grace period check box.
    What is the grace period?
  9. Go to Startup > Configure and download.
  10. In the Engineered devices tab, right-click a device.
  11. Select Load and then Full (device may restart) or Full with upload.
  1. The license is downloaded and operational.
