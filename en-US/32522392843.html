Examples: Event enrollment

Monitoring of In alarm, Fault, Overridden and Out of service

If changes to a data point status need to be reported or logged, monitoring can be carried out using the state flag property. This can be done with a multiple selection with an event enrollment, or specifically with several event enrollment objects.

  1. In the Plants navigation view, select the event enrollment object.
  2. Select the Properties tab on the right.
  3. Select the BACnet view option.
  4. From the Referenced property identifier drop-down list, select the value State flag to be monitored.
  5. From the Event type drop-down list, select Change of value.
  6. Select Event parameters.
  7. The Event parameters dialog box opens.
  8. Select the Bit mask option:
    • In the Bit mask drop-down list, check the desired check boxes for In alarm, Fault, Overridden or Out of service.
  10. Select OK.
  11. The Change of value event type for In alarm, Fault, Overridden or Out of service is configured.
  12. (Optional) Configure the event message text.
    Customizing event message texts for an event enrollment object
  13. (Optional) Change the notification class value.
    Note: The event enrollment object is always created with notification class 8 = Medium priority notification (Acknowledge).
    Alarm management by notification class

Configuring additional alarms

  • Define the high and low limit alarms for the data point.
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the I/O configuration task.
  4. In the Plants navigation view, select a datapoint, for example, room temperature.
  5. Select the Properties tab on the right.
  6. Select the Alarm tab.
  7. Define the properties according to the picture.
  • Create an additional alarm with an event enrollment.
  1. Open the BACnet references task.
  2. Select the Projects tab.
  3. In the Description column, enter, for example, room temperature.
  4. Select the room temperature.
  5. Right-click and select Create event enrollment object.
  • Configure the event enrollment object.
  1. Select the created event enrollment object.
  2. Select the Properties tab on the right.
  3. Select the All tab.
  4. In the Referenced property identifier drop-down list, select Present value.
  5. From the Event type drop-down list, select Out of range.
  6. Select Event parameters.
  7. The Event parameters dialog box opens.
  8. Define the properties according to the picture. In this example, the high limit value must be greater than 25 and the low limit value must be less than 15.
  10. Select OK.
  1. Additional high and low limit alarms are defined.
