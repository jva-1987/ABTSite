Discarding changes

The Discard changes function allows a BACnet client or application to undo any modifications that have been made to the properties of a BACnet object but have not yet been applied. This function is useful when the client wants to cancel or revert changes that were made to the object, without actually applying those changes.

- The discard changes function only applies to selected properties located in the same port object.
- A cross-port discard changes functionality is not available.
- Once activate changes has been performed, the changes cannot be undone.

  1. Go to the Object view tab.
  2. Select  Device.
  3. Select  Infrastructure > [network port name].
  4. Select .
  5. The [Network port] properties dialog area opens.
  6. Select the Network port command drop-down list and select Discard changes.
