Copying the activities of one day

With the copy function, entries can be easily duplicated for one or several days.

  1. While in Edit mode, select  Copy in the heading.
  3. The Select the day you want to copy dialog opens.
  4. Select the day to be copied.
  6. Select Next.
  7. The Select the days on which you want to repeat the exception schedule dialog opens.
  9. Select the target day(s) for your copy.
  11. Select Paste. Changes are automatically saved, and the copied day overwrites the day(s) it is pasted to.
