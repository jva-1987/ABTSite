Customizing event message texts for a scheduler object

The event message text can be used to define customer-specific event texts for each event status. The defined texts are forwarded to the management station or a printer when the event occurs.

  1. A scheduler object is in the control program created.
  2. The control program is opened.
  1. In the Project tree, select the Devices tab.
  2. Select [Plant name] > Resources > Coordination > [Scheduler name].
  3. Right-click and select Show in program.
  4. Select the Properties tab.
  5. Select the BACnet properties tab and then the All tab.
  6. Select the BACnet view option.
  7. Do the following:
    • In the Name column, select Event configuration.
    • In the drop-down list, select Intrinsic event reporting.
  8. Do the following:
    • In the Name column, select Configurable event message.
      Note: The maximum text length for all 3 entries is 255 characters.
    • In the [1] To offnormal field, enter a customized text.
    • In the [2] To fault field, enter a customized text.
    • In the [3] To normal field, enter a customized text.
  10. Select OK.

The Event message texts property is only visible online on the Web interface.
1. On the Web interface, select the scheduler object and open the [data point] Properties list.
2. Select the Event message texts section to display the assigned customized texts.
